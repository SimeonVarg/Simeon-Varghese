Light Ansible

A Python-based idempotent server provisioner with a Flask web dashboard. Enforces declared system state (packages, users, permissions, services, cron) via a config.yaml, streams real-time output over SSE, and generates structured JSON compliance reports. Includes --dry-run mode and a full pytest suite. Note: hosted on Render free tier — may take ~1 min to wake up.
